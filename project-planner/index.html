Make a yearly calendar for your client projects

  1. Mark the work you have already agreed to

    Create a color category for each client project and mark its start and end dates. Use the whole span to see how commitments sit across months, including review periods and handoffs.

  2. Put delivery windows and time off beside the projects

    Use another category for final reviews and deliveries, with the client name in each range note. Keep planned time away in its own category. This example uses all five available categories: three projects, delivery windows, and time off.

  3. Add the proposed dates before saying yes

    Mark the new project and its delivery window. Look for starts during existing handoffs, several deliveries close together, or review periods during time away. Check the project scopes and your availability separately before deciding what you can take on.

  4. Revise the proposal and confirm it with the client

    In your own YearMap, edit the proposed project range and its delivery window to compare another schedule. Add a note such as “November start pending client approval.” Update both ranges when the dates are agreed.

The year-at-a-glance view helps you compare dates. Keep detailed tasks, effort estimates, and dependencies in the tools you already use. Category day totals count calendar days, including weekends; they are not billable hours or working-day estimates.

Share a proposal the client can see

Once you have a schedule to discuss, create a read-only snapshot. A client can open the link on a phone or computer without installing YearMap. They can inspect the included ranges and notes, but cannot edit them.

Review the categories and notes you include before sending a link. Other clients’ names and dates may be confidential. Anyone with the link can see its included content. Read more about YearMap’s privacy practices.

A snapshot does not update when you change your plans. Create a new link after revising dates. You can also export ranges as an ICS file for another calendar app; this is a file download rather than a live calendar connection.

Project planning questions

Is this a task manager or Gantt chart?

YearMap shows date ranges and notes in a yearly calendar. Use it for the broad schedule alongside your task manager. It does not calculate dependencies, assign tasks, or track project completion.

How many projects can I show?

YearMap supports up to five color categories, each containing multiple ranges. This example uses three categories for projects and reserves two for delivery windows and time off.

Can the example be copied into my own YearMap?

The examples are read-only. Install YearMap and enter your own categories and dates; opening an example does not automatically import it into the extension.

Can clients edit the shared schedule?

No. Shared links show a read-only snapshot. Discuss changes with the client, edit your own calendar, then create a new snapshot when needed.

Can I plan projects on my phone?

Creating and editing plans requires YearMap in Chrome on a computer. Clients can view shared links in a phone’s browser.
